# CaptionLab Hosted Demo

The Streamlit interface is designed to make the image-captioning project understandable without requiring a full Flickr8k training run first.

## Two execution modes

### Custom attention checkpoint

When both files exist:

```text
models/best_model.pth
models/vocabulary.pkl
```

the demo loads the repository's custom captioning checkpoint. An attention-architecture checkpoint can display:

- the best generated caption,
- alternative beam-search captions,
- per-token confidence,
- the spatial attention map used for each generated word.

### Hosted reference fallback

The public demo branch intentionally does **not** commit large training artifacts. When a custom checkpoint is absent, it uses `microsoft/git-base-coco` as a clearly labelled reference captioner so the interface remains interactive.

The reference checkpoint is a Microsoft GIT (Generative Image-to-text Transformer) model fine-tuned on COCO and distributed on Hugging Face under the MIT license. It is not presented as a model trained by this repository.

## Run locally

From the repository root:

```bash
pip install -r demo/requirements.txt
streamlit run demo/app.py
```

The first reference-model generation downloads the Hugging Face checkpoint and may therefore take longer than subsequent cached requests.

## Streamlit Community Cloud

Recommended hosted branch configuration:

```text
Repository: SahilBh01r1769/image-captioning
Branch: demo/hosted-captioning
Main file: streamlit_app.py
Python: 3.11
```

The demo is intended as a project walkthrough, not a benchmark. Model-quality claims belong in reproducible evaluation artifacts generated by `evaluate.py`.
